# OBLIQUE

Локальный учебный магазин дизайнерской одежды и обуви на Flask и MariaDB с админ-панелью. Каталог и бренды читаются из БД; если официального фото пока нет, показывается типографическая заглушка.

## Установка (Windows / PowerShell)

Требуется Python 3.11+ и запущенная MariaDB на `127.0.0.1:3306`.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

В HeidiSQL создайте сессию MariaDB/MySQL: хост `127.0.0.1`, порт `3306`, пользователь `root`, пароль `1111`. Откройте `schema.sql` через **Файл → Загрузить SQL-файл**, затем нажмите **F9** для выполнения всего файла. Альтернативно `python seed.py` автоматически выполнит тот же SQL через PyMySQL, если база ещё не создана.

Настройки лежат в `.env` (пример без настоящих реквизитов в `.env.example`). Не публикуйте `.env`; замените `SECRET_KEY` и пароль администратора для своего локального экземпляра.

```powershell
.\venv\Scripts\python.exe seed.py
.\venv\Scripts\python.exe app.py
```

Магазин: <http://127.0.0.1:5000/>. Админ-панель: <http://127.0.0.1:5000/admin/>. По умолчанию: `admin@example.com` / `admin12345` (значения берутся из `.env` при первом заполнении БД). Повторный запуск seed не сбрасывает существующие товары и пароль.

## Изображения

Добавляйте **только официальные изображения** из пресс-китов брендов, лукбуков, официальных каталогов либо у авторизованных дилеров при наличии разрешения. Не используйте неофициальные подборки. Загрузите JPG, PNG или WebP через форму товара в админке; сервер проверяет реальный формат, преобразует изображение в WebP, создаёт миниатюру и сохраняет в `static/img/products/{brand-slug}/{product-slug}-{номер}-{случайный-суффикс}.webp`. В базе хранятся только относительные пути. Пока изображения отсутствуют, витрина показывает заглушку с названием товара.

## Данные

`seed.py` добавляет семь дизайнеров, четыре товара каждого бренда, размеры с остатками и первого администратора. Схема находится в `schema.sql` и совместима с HeidiSQL. Заказы сохраняются в `orders`/`order_items`; отмена возвращает позиции в остатки.

Для локальной проверки основных сценариев: `.\venv\Scripts\python.exe smoke_test.py`.

Витрина поддерживает фильтры бренда, категории, размера и цены, сессионную корзину и оформление заказа. В админке доступны редактирование брендов/категорий/товаров, управление изображениями и остатками, фильтры заказов, экспорт CSV и журнал действий. CSS/JS работают локально; анимации GSAP и плавный скролл Lenis загружаются с CDN в фиксированных версиях и при недоступности CDN базовый интерфейс остаётся работоспособным.

## Обновление каталога из image_sources.md

`update_catalog.py` читает все подписанные ссылки из `image_sources.md`, проверяет реальные типы файлов через Pillow, конвертирует их в локальный WebP и связывает с соответствующими товарами. Скрипт не изменяет цены, которые уже были вручную отредактированы в админке. Сейчас два URL Clothbase (Raf Simons Edition Coat и Yohji Yamamoto Edition Coat) недоступны с их стороны, поэтому эти две карточки используют штатные заглушки; повторный запуск скрипта автоматически добавит изображения, когда источники станут доступны.
